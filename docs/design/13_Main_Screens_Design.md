# 13. ออกแบบหน้าจอหลัก — เช่น หน้าเข้าสู่ระบบ Dashboard และหน้าบันทึกงาน

เอกสารนี้ระบุรายละเอียดโครงสร้างและองค์ประกอบของหน้าจอหลักทั้ง 5 หน้าจอในระบบ **เว็บแอปพลิเคชันคลังคำศัพท์ Flashcard ช่วยจำสอบภาษาอังกฤษ** เพื่อใช้เป็นแนวทางมาตรฐานในการพัฒนาฝั่งหน้าบ้าน (Frontend Development)

---

### 1. หน้าจอที่ 1: หน้าเข้าสู่ระบบ (Login Screen)

* **วัตถุประสงค์:** ใช้ระบุตัวตนและตรวจสอบสิทธิ์ผู้ใช้งานก่อนเข้าถึงคลังคำศัพท์ส่วนตัว
* **โครงสร้างการจัดวาง (Layout Architecture):**
  * **Header:** แสดงสเตตัสบาร์มาตรฐานของอุปกรณ์เคลื่อนที่ (เวลา 9:41, สัญญาณเครือข่าย 5G และแบตเตอรี่ 100%)
  * **Brand Section:** โลโก้กล่องสี่เหลี่ยมโค้งมนสีน้ำเงิน บรรจุไอคอนสมุดคำศัพท์ ตามด้วยชื่อระบบ `Student Vocab` (ขนาด 24px Bold) และคำอธิบายย่อย `เข้าสู่ระบบเพื่อจัดการคลังคำศัพท์และเริ่มเรียน`
  * **Input Form:**
    * Label: `อีเมลหรือชื่อผู้ใช้ (email / username) *` (ขนาด 13px)
    * Text Input Field: แสดงค่าตัวอย่าง `theeradech_019@vec.go.th` ขอบมน 8px พื้นหลังสีเทาอ่อน
    * Label: `รหัสผ่าน (password_hash) *` (ขนาด 13px)
    * Password Input Field: ซ่อนอักขระเป็นจุด `••••••••` ขอบมน 8px
  * **Action Button:** ปุ่มกดเต็มความกว้าง (Full Width) สีน้ำเงิน `#2563EB` ข้อความสีขาว `เข้าสู่ระบบ` (ความสูง 48px)
  * **Footer Link:** ข้อความเชื่อมโยง `ยังไม่มีบัญชี? สมัครใช้งาน` (สามารถกดสลับเป็นฟอร์มสมัครสมาชิก Register ได้)
  * **Bottom Navigation Bar:** แถบเมนูด้านล่าง 2 ปุ่ม ได้แก่ [เข้าสู่ระบบ (ไฮไลต์), ความช่วยเหลือ] ตรงตาม Wireframe ต้นฉบับ
  * **คำอธิบายใต้ภาพ:** `หน้า 1: Login - การตรวจสอบสิทธิ์ผู้ใช้ เชื่อมโยงตาราง users`

### 2. หน้าจอที่ 2: แดชบอร์ดสรุปผล (Dashboard Screen)

* **วัตถุประสงค์:** แสดงภาพรวมคลังคำศัพท์ สถิติการจำ รายการคำศัพท์เร่งด่วนที่ต้องทบทวนซ้ำ และการจัดการคำศัพท์ (แก้ไข / ลบ)
* **โครงสร้างการจัดวาง (Layout Architecture):**
  * **User Header:**
    * แสดงคำทักทาย `สวัสดี คุณธีรเดช` (ขนาด 18px Bold)
    * ระบุกลุ่มเป้าหมาย `เป้าหมายสอบ: TOEIC & IT`
    * ปุ่มลัดมุมขวาบน `+ เพิ่มศัพท์` สีน้ำเงินขอบมน (เปิดฟอร์มสร้างคำศัพท์ใหม่)
  * **Stats Summary Cards (การ์ดสถิติ 3 ช่อง):**
    * บล็อกที่ 1: ตัวเลขขนาดใหญ่ `5` คำบรรยาย `คำศัพท์ทั้งหมด` (สีน้ำเงิน)
    * บล็อกที่ 2: ตัวเลขขนาดใหญ่ `2` คำบรรยาย `จำได้แล้ว` (สีเขียว `#10B981`)
    * บล็อกที่ 3: ตัวเลขขนาดใหญ่ `3` คำบรรยาย `ยังจำไม่ได้` (สีแดงส้ม `#EF4444`)
  * **Progress Tracker:**
    * หัวข้อ `ความคืบหน้าเป้าหมายคำศัพท์` และเปอร์เซ็นต์ความสำเร็จ `40%`
    * แถบ Progress Bar ความยาวเต็มกรอบ โดยมีแถบสีเขียวเติม 40%
  * **Priority Review Section (คำศัพท์ที่ต้องรีบทบทวน & ปุ่มจัดการ Edit/Delete):**
    * หัวข้อ `คำศัพท์ที่ต้องรีบทบทวน (ยังจำไม่ได้)` (ขนาด 16px Bold)
    * แสดงรายการแบบ List Item แต่ละแถวประกอบด้วย:
      1. คำศัพท์หลักตัวหนา (เช่น `Implement`, `Requirement`, `Deploy`)
      2. ป้ายกำกับหมวดหมู่ด้านขวา (Badge สีส้ม/เหลือง `TOEIC`, `IT Vocab`)
      3. คำแปลภาษาไทยด้านล่างสีเทาเข้ม
      4. ปุ่มคำสั่งจัดการด่วน:
         * ปุ่มไอคอน `[✏️]` (Edit): สลับไปยังหน้าฟอร์มแก้ไขข้อมูลคำศัพท์
         * ปุ่มไอคอน `[🗑️]` (Delete): เรียกหน้าต่าง Modal ยืนยันการลบ
  * **Bottom Navigation Bar:** แถบเมนูด้านล่าง 4 ปุ่ม ได้แก่ [หน้าหลัก (ไฮไลต์), ท่องการ์ด, ทดสอบ, โปรไฟล์]
  * **คำอธิบายใต้ภาพ:** `หน้า 2: Dashboard - สรุปสถิติจำนวนคำศัพท์ คลังคำศัพท์ และปุ่มแก้ไข/ลบ`

### 3. หน้าจอที่ 3: โหมดท่องการ์ด (Flashcard Study Mode)

* **วัตถุประสงค์:** จำลองการท่องจำด้วยบัตรคำศัพท์จริง สามารถพลิกดูเฉลย กดบันทึกความจำ และจัดการแก้ไขหรือลบคำศัพท์ปัจจุบัน
* **โครงสร้างการจัดวาง (Layout Architecture):**
  * **Top Bar:** หัวข้อ `โหมดท่องการ์ด` และปุ่มลัด `+ เพิ่มศัพท์`
  * **Filter Pill Buttons (ปุ่มกรองสถานะ):**
    * ปุ่ม `[ทั้งหมด (5)]`
    * ปุ่ม `[ยังจำไม่ได้ (3)]` (สถานะ Active: พื้นหลังสีน้ำเงิน/ตัวอักษรขาว)
    * ปุ่ม `[จำได้แล้ว (2)]`
  * **Flashcard Canvas (ตัวการ์ดคำศัพท์ 3D Flip):**
    * การ์ดสีขาว เส้นขอบบาง ไม่มีเงา มุมโค้ง 8px พื้นที่ตรงกลางมีระยะขอบสม่ำเสมอ
    * ด้านบนของการ์ด: แสดงป้ายหมวดหมู่ `TOEIC`, ชนิดของคำ `Noun`, และปุ่มคำสั่งด่วน:
      * `[✏️ แก้ไขคำนี้]`: โหลดข้อมูลคำปัจจุบันเข้าสู่ฟอร์มแก้ไข
      * `[🗑️ ลบคำนี้]`: เรียก Modal ยืนยันการลบคำศัพท์ปัจจุบัน
    * คำศัพท์หลัก: `Requirement` (ขนาด 24px กึ่งกลางการ์ด)
    * ปุ่มฟังเสียงอ่าน (TTS Audio): ไอคอนรูปลำโพง 🔊 กดฟังการออกเสียงภาษาอังกฤษ
    * คำแปลภาษาไทย: `ความต้องการ, เงื่อนไขที่จำเป็น` (ขนาด 16px)
    * กรอบตัวอย่างประโยค: `"The client outlined new software requirements."` (พื้นหลังสีเทาอ่อน ตัวเอียง ขนาด 13px)
    * คำแนะนำการโต้ตอบ: `คลิกเพื่อพลิกดูคำแปล / เฉลย`
    * ลำดับการ์ด: `การ์ด 2 / 3`
  * **Memory Assessment Buttons (ปุ่มประเมินตนเอง):**
    * ปุ่มแดงด้านซ้าย: `✕ ยังจำไม่ได้` (สีแดง `#EF4444` ข้อความสีขาว)
    * ปุ่มเขียวด้านขวา: `✓ จำได้แล้ว` (สีเขียว `#10B981` ข้อความสีขาว)
  * **Pagination Navigation:** ปุ่มลูกศร `< คำก่อนหน้า` และ `คำถัดไป >`
  * **Bottom Navigation Bar:** แถบเมนูด้านล่าง 4 ปุ่ม โดยไฮไลต์ปุ่ม "ท่องการ์ด"
  * **คำอธิบายใต้ภาพ:** `หน้า 3: โหมดท่องการ์ด - คลิกพลิกดูคำแปล บันทึกสถานะ พร้อมปุ่มแก้ไข/ลบ`

### 4. หน้าจอที่ 4: เพิ่มและแก้ไขการ์ดคำศัพท์ (Add & Edit Flashcard Screen)

* **วัตถุประสงค์:** แบบฟอร์มสำหรับผู้เรียนในการเพิ่มคำศัพท์ใหม่ (INSERT) หรือแก้ไขข้อมูลคำศัพท์เดิม (UPDATE) เช่น คำแปล ชนิดของคำ หรือตัวอย่างประโยค
* **โครงสร้างการจัดวาง (Layout Architecture):**
  * **Top Bar:** ปรับข้อความหัวข้อตามโหมด:
    * โหมดสร้างใหม่: `เพิ่มการ์ดคำศัพท์ใหม่`
    * โหมดแก้ไข: `แก้ไขข้อมูลคำศัพท์`
  * **Hidden Input Field:** `#edit-vocab-id` เก็บ ID ของคำศัพท์ที่กำลังแก้ไข
  * **Form Fields:**
    1. `คำศัพท์ภาษาอังกฤษ (vocab_word) *`: ช่องป้อนข้อความ ระบุค่า `Requirement`
    2. `ชนิดของคำ (part_of_speech)`: ช่องเลือก/ป้อน ระบุค่า `Noun (คำนาม)`
    3. `หมวดหมู่คำศัพท์ (category_id) *`: Dropdown Menu เลือกค่า `TOEIC`, `IT Vocab` ฯลฯ
    4. `คำแปลภาษาไทย (meaning_th) *`: ช่องป้อนข้อความ ระบุค่า `ความต้องการ, เงื่อนไขที่จำเป็น`
    5. `ตัวอย่างประโยค (example_sentence)`: ช่องข้อความหลายบรรทัด (Textarea) ระบุค่า `The user outlined system requirements.`
  * **Action Buttons:**
    * ปุ่มบันทึก: ปรับเปลี่ยนข้อความระหว่าง `บันทึกคำศัพท์` (เพิ่มใหม่) หรือ `บันทึกการแก้ไข` (แก้ไขเดิม) สีน้ำเงิน `#2563EB`
    * ปุ่มยกเลิก: `ยกเลิก` สีเทาขอบบาง คืนค่าฟอร์มและกลับสู่หน้าจอก่อนหน้า
  * **Bottom Navigation Bar:** แถบเมนูด้านล่าง 4 ปุ่ม ไม่มีปุ่มไฮไลต์ (หน้านี้เข้าจากปุ่ม "เพิ่มศัพท์" ในหน้าหลัก)
  * **คำอธิบายใต้ภาพ:** `หน้า 4: เพิ่ม/แก้ไขการ์ดคำศัพท์ - ฟอร์มบันทึกและอัปเดตข้อมูลการ์ดลงตาราง flashcards`

### 7. หน้าต่างยืนยันการลบคำศัพท์ (Delete Confirmation Modal Dialog)

* **วัตถุประสงค์:** ป้องกันการกดลบคำศัพท์โดยไม่ได้ตั้งใจ (Accidental Deletion) เพื่อความปลอดภัยของข้อมูลผู้ใช้งาน
* **โครงสร้างการจัดวาง (Layout Architecture):**
  * **Overlay Backdrop:** ฉากหลังสีดำโปร่งแสง (`rgba(0, 0, 0, 0.6)`) ซ้อนทับทั้งหน้าจอ
  * **Modal Container:** กล่องป็อปอัปสี่เหลี่ยมโค้งมนสีขาว (`border-radius: 16px`) ลอยเด่นกึ่งกลาง
